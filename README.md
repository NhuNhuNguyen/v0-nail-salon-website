# MK Fashion Nails & Spa - Scarborough Website

A high-performance, mobile-first static website for **MK Fashion Nails & Spa**, located at 579 Markham Rd, Scarborough. Built with AI-assisted development and optimized for local SEO.

## 🛠️ The Tech Stack
* **AI Builder:** [v0.dev](https://v0.dev) (UI & Component generation)
* **Code Editor:** Visual Studio Code (Maintenance & Updates)
* **Framework:** React.js / Next.js with Tailwind CSS
* **Deployment:** Netlify (Automated from GitHub)

---

## 💅 Service & Repair Policy (Updated 2026)
To ensure business sustainability and fair service for all Scarborough clients, the website now reflects the following:
* **3-Day Quality Check:** Complimentary repairs are provided for chips or lifting within **3 days** of service.
* **Durability Focus:** We emphasize high-quality products and professional application rather than a specific multi-week time guarantee.
* **No Refunds:** Policy clearly states no refunds once the client leaves the salon, focusing on "making it right" via the 3-day window.

---

## 🚀 How to Update the Site
1. **Small Updates:** Use **VS Code** to edit `page.tsx` or `App.tsx` for quick text/price changes.
2. **Design Changes:** Use **v0.dev** to generate new sections, then paste the code into VS Code.
3. **Go Live:** `git push` to the main branch. Netlify will deploy the changes to the live site instantly.
